# itty-aucrocy

A beginner-friendly open-source project created to help new contributors practice GitHub workflows, documentation editing, and pull requests. This repository is intentionally simple and serves as a safe space for students and first-time open-source contributors.

---

## 📘 Purpose

The main goal of this project is to provide a straightforward “Good First Issue” for new contributors who want to learn how to:

- Fork a GitHub repository  
- Clone a project to their local machine  
- Create and switch between branches  
- Edit documentation  
- Commit and push changes  
- Open a pull request  
- Engage with basic open-source contribution workflows  

This repository is not designed for complex coding — it exists as a practice environment for documentation and Git fundamentals.

---
